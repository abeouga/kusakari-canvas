# 植物サイズ制御方式の判断

## Context：確認した事実

利用者の条件は、庭写真と3D配置を重ねた全景を入力し、APIが返した全景をAfterとして使うことです。遮蔽補助も同じ庭・画角で作成します。位置精度は現状で許容済みですが、植物サイズの明らかな拡大は許容されたと解釈しません。

| 既存の評価 | 単体の幅の概測 | 確認できること |
| --- | --- | --- |
| 同じ入力・指示でmedium / high | 約1.44倍 / 1.41倍 | この2枚ではhighでも拡大が残った |
| 短く整理した指示v2 | 約1.42倍 | 指示整理後も拡大が残った |
| 同じv2でマスクの余裕を8pxから0pxへ変更 | 約1.48倍 | 元の植物画素だけを編集対象としても拡大した |

根拠は[品質比較](ai-quality-medium-high-evaluation.md)、[候補指示の評価](ai-prompt-practical-review.md)、[マスク評価](ai-plant-size-mask.md)です。各条件の標本数は少なく、成功率や条件間の優劣を推定できません。幅は手動の概測で、最新結果の端点誤差は約±5pxです。

最新のBefore / Afterを目視し、`artifacts/e2e/ai-quality/mask-margin-assessment.json`の結果も確認しました。元の植物画素範囲は100×109px、Afterの外形は概ね147×128px。旧目視基線99×107pxを分母にすると幅約1.48倍です。入力の画素範囲と旧目視基線を同じ測定値として扱いません。

現在の`ai_service.py`は主画像、同画角の補助画像、植物参考写真を順に送ります。`ai_provider.py`は画像編集APIを1回呼び、`ai_images.py`は出力の右・下の余白だけを除きます。既存の監査では余白除去後のAPI出力とAfterの不一致は0画素です。確認した拡大を表示・保存時の拡縮で説明する根拠はありません。

[OpenAI公式画像生成ガイド](https://developers.openai.com/api/docs/guides/image-generation#edit-an-image-using-a-mask)をこの判断時に再確認しました。GPT Imageのマスクは指示として働き、正確な形状に完全に従うとは限りません。複数画像の場合は先頭画像がマスク対象です。これは今回の拡大原因を特定した説明でも、全モデル・全入力でサイズ保持が不可能という証明でもありません。

## Decision：現行方式の追加調整を止め、サイズ要件を未達のまま明示する

現行の全景生成は、ビフォーアフターの完成イメージを作る機能として維持できます。ただし、配置サイズを安定して保持する方式として採用を確定できません。マスク0pxや指示v2を通常利用へ昇格させず、品質・文言・マスク幅だけを変える再生成を追加しません。

現時点の推奨は、サイズ要件を維持することです。その場合、次の作業は別の生成方式が必要条件を満たすかの調査です。採用するサービスやモデルはまだ決められません。深度・輪郭などを生成処理の専用条件として受け取れる方式が候補ですが、専用条件の存在だけでサイズ保持を保証しません。通常の参考画像として深度図を追加することとも区別します。

サイズ差を許容して現行方式を完成イメージ用途で確定する案は、利用者による要件変更が必要です。位置精度の許容を、その変更の代わりに使いません。

## Alternatives：選択肢と条件

| 選択肢 | 得られるもの | 制約・判断 |
| --- | --- | --- |
| 現行の全景生成を完成イメージ用途として採用 | 既存の生成・保存・比較の流れを利用できる | サイズ差を利用者が許容する必要がある。注意書きや比較表示を追加してもサイズ修正にはならない |
| 全景生成を保ち、専用の構造条件を受け取れる方式を調査 | 現行とは異なる制御手段を評価できる可能性がある | 推奨する次の調査。対応API、実行環境、費用、制御効果は未確認。新規実装・課金実験の開始を意味しない |
| 庭写真と3Dの描画結果を完成画像に使う | 同一カメラとモデルで投影寸法を決められる | 写実性はモデル・材質・照明の品質に依存する。AI生成全景をAfterにする目的を変更するため、現時点では採用しない |
| 生成した植物を拡縮して元の庭へ貼り戻す | 出力領域を局所的に制御できる | 利用者の条件に反するため採用しない |

参考写真を外す、入力の3Dをあらかじめ縮める、別モデルへ変える、再生成を選別する方法にも、現在の証拠から安定したサイズ保持を期待する根拠はありません。参考写真が拡大の原因という仮説は未検証です。1.48倍の逆数を入力へ掛ける補正は、別の植物・画角・遮蔽で成立するか不明なため採用しません。
