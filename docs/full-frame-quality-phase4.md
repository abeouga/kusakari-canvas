## Decision：評価機構

`ai_evidence.py` は生成ID別の新規フォルダーへ `provider.png`、`after.png`、`prompt.txt`、送信時のみ `mask.png`、モデル・寸法・入力順・SHA-256の `metadata.json` を保存します。キー、ヘッダー、SDK応答全体は保存しません。

`AiSettings.evidence_directory` はE2Eプロファイルで、`KUSAKARI_CANVAS_AI_LIVE=1`、`KUSAKARI_CANVAS_AI_QUALITY_LIVE=1`、`KUSAKARI_CANVAS_AI_EVIDENCE_DIR` がある場合だけ有効です。通常プロファイルでは無効です。既存証拠を上書きせず、証拠保存のI/O障害で生成結果を失わせません。証拠が欠けた場合は評価側で失敗とします。

比較用の `KUSAKARI_CANVAS_AI_MASKLESS=1` もE2E＋実生成フラグ2つの場合だけ有効です。maskのSDK引数を省略し、マスク説明3文だけを指示から除去します。可視植物の事前検査は残し、画面やAPI要求に切替を追加していません。

| 配置 | 責務 |
| --- | --- |
| `backend/kusakari_canvas_api/ai_evidence.py` | 証拠の保存と上書き防止 |
| `ai_config.py` / `ai_service.py` | E2E限定設定と生成・証拠保存・履歴保存の順序 |
| `ai_provider.py` / `ai_prompt.py` | 比較時のマスク省略と説明省略 |
| `e2e/ai-quality-evidence.ts` | 元出力とAfterの画素・バイト一致検査 |
| `e2e/ai-quality.spec.ts` | 実画面・実API・実MySQLの生成・保存・再表示 |
| `e2e/ai-history-recovery-live.spec.ts` | 実保存障害からの復旧 |
| `backend/verification/verify_ai_evidence.py` | 通常環境の設定拒否とファイル保存障害の独立検証 |

設定拒否・証拠保存障害は課金E2Eでは安定して作れないため独立検証しています。正常系APIはモックで代替していません。課金評価のPlaywrightレポートは実行名ごとに保存します。

## 画質の結果

| ケース | 判定 | 確認した問題 |
| --- | --- | --- |
| 単体・マスクあり | 要修正 | 低木の幅約2.29倍、高さ約1.97倍。樹冠中心は約47px移動 |
| 複数・マスクあり | 要修正 | 木の幅約3.81倍、高さ約2.14倍、樹冠中心約113px移動。低木も幅約1.50〜1.67倍 |
| 重なり・マスクあり | 破綻 | ベンチが消失。一部見えていた2つの低木も消失。木の根元は約19px移動 |
| 重なり・マスクなし | 破綻 | ベンチが消失。元はベンチに隠れていた領域へ低木が露出。木の大きさ・根元も変化 |

数値は原寸で主要外形を読み取った近似値です。葉先座標には約±2pxの不確実性があり、閾値に近い個別の根元測定は合格と断定しません。大幅な拡大・家具消失の判定はこの不確実性では逆転しません。座標・計算は各ケースの `visual-assessment.json` にあります。

固定物5点のうち3点は相関閾値0.80以上、変位0〜1pxでした。残る2点は相関約0.64〜0.73で判定不能です。構図全体の完全保持を確認したとは扱いません。`fixed-measurements.json` に生データを保存しました。

目視では葉先と接地は概ね自然で、矩形切断は今回確認しませんでした。ただし位置・寸法・前後関係が不合格のため採用しません。完全遮蔽の植物の外観は事前定義どおり採点対象外です。

## マスク比較と不確実性

重なりの代表ケースで、画像bytes・順序・モデル・品質・寸法を揃え、マスク説明以外の指示が同一であることを確認しました。マスクなしでも家具消失が残り、採用条件を満たしません。通常設定のマスクは維持しています。

各条件1回のため、マスクの因果効果や成功率は推定できません。補助画像を主画像として解釈した可能性、参考画像の成木寸法に引かれた可能性は仮説です。確認できた事実は「送信順は正しく、指示に反した変形・消失がAPI元出力に含まれる」ことです。

[OpenAI公式ガイド](https://developers.openai.com/api/docs/guides/image-generation)ではマスクは編集ガイドで、厳密な形状保持の保証ではありません。今回の比較も構造保持の保証として扱いません。
